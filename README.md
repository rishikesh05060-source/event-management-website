# Evently — Event Management Website

A responsive event discovery and registration website built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. No build tools or dependencies are required.

## Features
- Responsive layout for mobile, tablet and desktop.
- Event cards with images, dates, venues, categories and descriptions.
- Live keyword search and category filtering.
- Event detail dialog with registration action.
- Registration form with JavaScript validation for name, email, Indian mobile number and selected event.
- Confirmation message after successful validation.
- Keyboard-accessible event cards and mobile navigation.

## Important demo note
The form validates input in the browser and displays a confirmation. It does not save registrations or send data to a server. A real deployment needs a backend/API and database.
